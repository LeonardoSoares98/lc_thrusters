# LC_Thrusters - FiveM

## About
A cold-gas thruster package for vehicles. Equipped cars get boost nozzles, lift thrusters for short hops and hovers, a flight computer that keeps them stable and lands them softly, stunt control in the air and an underbody fan that holds them on loops and walls.
